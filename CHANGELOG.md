# Changelog

## 1.1.0

- The parts of VS Code that came after 2024 now follow the theme instead of the default grey and black: menus, the Command Center,
  Quick Open and the Command Palette, the terminal (with ANSI colors), panels, notifications, tabs, breadcrumbs, sticky scroll,
  git decorations, the gutter, chat and the agents views. The editor and all syntax colors are unchanged.

## 1.0.0

First release on the VS Code Marketplace and Open VSX. The colors are unchanged from the version Birdycom has used since 2024.

- Shown as **Birdycom Omnia Dark** in the stores; in the theme picker it is still **Omnia Theme Main**.
- New icon, README and screenshots.
- License: the MIT notice of One Dark, the theme Omnia Theme started from, is now included.

## 0.1.0

- Starting from One Dark.
- Custom colors for HTML, PHP and Blade, CSS, SCSS, Less, JavaScript, JSON, YAML, Markdown and Python.
